# Support

Use the following channel for the kind of help you need:

- Questions and setup help: [GitHub Discussions](https://github.com/KenmogneThimotee/plinthway/discussions)
- Reproducible bugs: [bug report](https://github.com/KenmogneThimotee/plinthway/issues/new?template=bug_report.yml)
- Feature proposals: [feature request](https://github.com/KenmogneThimotee/plinthway/issues/new?template=feature_request.yml)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public issue

Before asking, check the [README](README.md), [configuration guide](docs/configuration.md), [MCP guide](docs/mcp.md), and [troubleshooting guide](docs/troubleshooting.md). Include `plinthway --version`, the operating system, Node.js version, the command used, and a minimal redacted reproduction. Never post credentials, tokens, private profile files, or sensitive MCP responses.

Support is community-maintained and has no guaranteed response time.
