## [0.1.0] - 2026-10-24

### Added

- Local-first terminal chat and one-shot execution with durable profile-scoped sessions.
- Searchable Models.dev catalog with provider grouping and compatible built-in adapters.
- OpenAI, Anthropic, Google Gemini, OpenAI-compatible, and eligible ChatGPT subscription authentication.
- Explicit persistent MCP server connections and the MCP `2026-07-28` client surface, including opt-in Tasks, Skills, Apps, and authorization extensions.
- Policy-controlled native filesystem and shell tools.
- Non-destructive migration from legacy Local Agent Harness state and keyring entries.
